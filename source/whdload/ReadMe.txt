WORLD OF STRONKIE REMAKE - WHDLoad version
Created By Mark Stronks, Stronkie Soft

INSTALL
  Copy the drawer WorldOfStronkieRemake to your hard drive (or CF card).
  Later chapters go into the SAME drawer: unpack the WHDLoad archives of
  all chapters on top of each other. Then each chapter finds the story
  of the chapter before it (WOSR.ST2 ... in the drawer "data").
  WHDLoad must be installed (C:WHDLoad), see www.whdload.de.
  Double click the WOS2 icon in the drawer to play.

NEEDS
  WHDLoad, 1 MB chip memory, 512 KB other memory for the Kickstart
  image (plus what WHDLoad needs itself), and the Kickstart 3.1 image of
  the A600 (kick40063.A600) in DEVS:Kickstarts. Runs on a 68000.
  No fast memory? Then start the game program straight from
  the data drawer: the game runs from a hard drive or CF card without
  WHDLoad on an A500 with 1 MB chip memory and Kickstart 3.1.

KEYS
  F10   quits back to the Workbench (any time)
  F5    the game's menu (save, load, music, dev mode, quit)

SAVES
  Your saved games are written into the drawer "data" (WOS2.SAV1-4),
  and the story for the next chapter too (WOSR.ST2).

FILES
  WOS2.slave       the WHDLoad slave (Kickstart 3.1 emulation)
  WOS2.info        the icon (default tool WHDLoad, SLAVE=WOS2.slave)
  data/WOS2        the game (the same files as on the disk)
  data/WOS2.DAT, data/WOS2.GFX, data/WOS2.STR
